# End-to-End Medical Chatbot – Generative AI

## Project Overview

This project is an AI-powered medical chatbot designed to provide
medical information based on user symptoms and health details.

The system uses Generative AI, Retrieval-Augmented Generation (RAG),
LangChain, and a Large Language Model to generate informative responses.

## Technologies Used

- Python
- Flask
- Generative AI
- RAG (Retrieval-Augmented Generation)
- LangChain
- LLaMA
- Groq
- Hugging Face
- ChromaDB
- Pinecone
- HTML
- CSS
- JavaScript

## Features

- Symptom-based medical information
- AI-powered chatbot
- Retrieval-Augmented Generation
- Medical document retrieval
- User-friendly web interface
- Voice input support
- Disease and medicine information
- Health information based on user details

## Project Architecture

User
↓
Flask Web Application
↓
LangChain
↓

RAG Pipeline
↓
Vector Database
↓
Large Language Model
↓
AI Generated Response
